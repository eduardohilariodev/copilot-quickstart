# Example: Target Repo Configuration

This directory shows a **fully populated target repo** that has been configured using copilot-quickstart meta-skills. It demonstrates the output you'd get when running the meta-skills against a TypeScript/Next.js project.

## Scenario

- **Repo:** `acme/web-platform`
- **Stack:** Next.js 14, TypeScript, Prisma, Tailwind CSS
- **Testing:** Vitest + Playwright
- **Architecture:** Monorepo (Turborepo)
- **Risk level:** Medium
- **Providers:** Copilot + Claude

## Files Generated

```
target-repo/
├── .github/
│   └── copilot-instructions.md   ← Generated by create-instructions
├── AGENTS.md                      ← Generated by create-instructions
├── CLAUDE.md                      ← Generated by sync-config (from copilot source)
└── repo-profile.yml               ← Input to all meta-skills
```

## How This Was Generated

1. Filled out `repo-profile.yml` with project details
2. Ran `create-instructions` → produced `.github/copilot-instructions.md`
3. Ran `sync-config` with source=copilot, target=claude → produced `CLAUDE.md`
4. Ran `evaluate-config` → confirmed compliance score of 4.6/5.0
