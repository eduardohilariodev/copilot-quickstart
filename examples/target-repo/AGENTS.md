## Project Overview

Customer-facing web platform with dashboard, auth, and billing. Monorepo managed by Turborepo with Next.js frontend, API service, and shared packages.

## Architecture

- **Type:** Monorepo (Turborepo)
- **Primary languages:** TypeScript, SQL
- **Key frameworks:** Next.js 14, Prisma, Tailwind CSS, Vitest, Playwright

## Directory Structure

```
├── apps/
│   ├── web/          # Next.js customer dashboard
│   └── api/          # API service
├── packages/
│   ├── ui/           # Shared React component library
│   ├── db/           # Prisma client and schemas
│   └── config/       # Shared ESLint, TypeScript configs
├── prisma/
│   └── migrations/   # ⚠️ Protected — do not auto-modify
└── turbo.json
```

## Key Conventions

### Naming

- Variables: camelCase
- Components: PascalCase
- Files: kebab-case
- Test files: `*.test.tsx` / `*.test.ts` (co-located)

### Code Organization

- Feature code lives in the app that uses it
- Shared logic moves to `packages/` only when used by 2+ apps
- Each package has its own `tsconfig.json` extending root config

### Error Handling

- API routes return typed error responses: `{ error: { code: string, message: string } }`
- Use Result pattern (`Result<T, E>`) for operations that can fail predictably
- Unexpected errors bubble to error boundaries (UI) or global handler (API)

### Testing

- Unit tests: Vitest, co-located, mock external deps
- E2E tests: Playwright, in `apps/web/e2e/`
- Coverage target: 80% for new code
- CI runs full test suite on PR

## Important Architectural Decisions

1. **Server Components by default** — Reduces client bundle size; only opt into "use client" for interactivity (forms, state, effects).
2. **Database access through packages/db only** — Prevents circular deps and ensures all queries go through typed Prisma client with consistent error handling.
3. **Zod for API validation** — Single source of truth for request/response shapes; generates types and validates at runtime.

## Protected Paths

These paths should not be auto-modified without human review:

- `prisma/migrations/` — Applied migrations are immutable
- `.env*` — Environment configuration
- `packages/config/` — Shared build configuration affects all packages
