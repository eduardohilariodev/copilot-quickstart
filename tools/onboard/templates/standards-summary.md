1. `.ai/system/standards.json` records which upstream version this repo was generated from.

| Frequency | Action | Skill/Command |

If the upstream standards version is newer than your local snapshot:
- `detect-drift` will flag the version difference
- Review the upstream changelog for breaking changes
- Re-run the CLI to regenerate the capsule (your custom content below the markers is preserved)
