## What This Repo Uses

This repository follows the [copilot-quickstart](https://github.com/eduardohilariodev/copilot-quickstart/tree/v1.0.0/source-of-truth) standards for AI-assisted development configurations.

### Artifact Types

| Artifact | Purpose | Location |
|----------|---------|----------|
| **Agent** | Autonomous task executor with tool access | `agents/` |
| **Skill** | Reusable capability unit (prompt + tools + constraints) | `.github/skills/` |
| **Instruction** | Behavioral directive shaping agent behavior | `.github/copilot-instructions.md` + `.github/instructions/` |
| **Documentation** | Context for humans and agents | `AGENTS.md` |

### Key Rules

- Each fact lives in exactly one place — no duplication across configs.
- Instructions are imperative, specific, atomic, and testable.
- Skills are self-contained: declared inputs, declared outputs, no ambient state.
- Security constraints have highest precedence and cannot be overridden.
- Generated artifacts include provenance metadata (standards version, source).

### Size Budgets

| File | Max Lines |
|------|-----------|
| Repo-wide instructions | 80 |
| AGENTS.md | 120 |
| SKILL.md | 200 |
| Path-specific instructions | 40 |

### How to Extend

- **New skill:** Follow the naming pattern in AGENTS.md. Place in `.github/skills/`.
- **New instruction:** Place in `.github/instructions/` with `applyTo` glob.
- **Modify standards:** Read `.ai/system/standards.json` for upstream reference.
