## AI Maintenance

Keep AI configuration healthy with periodic checks:

- **Weekly:** Run `health-dashboard` — check overall config alignment
- **Monthly:** Run `audit-skills` + `detect-drift` — find stale skills and provider inconsistencies
- **Quarterly:** Run `prune-skills` + `check-policy` — archive unused skills, verify governance
- **On change** (new service, provider, or major refactor): Run `evaluate-config` + `sync-config`

To re-onboard or reset: run the Onboard & Diagnose agent or `copilot-quickstart --stage`.
